# chaika

Skill для Чайки (`chaika.com`) и возмещения ДМС в АльфаСтраховании
(`med.alfastrah.ru`), применимый в Codex и Claude Code. Основной сценарий использует
браузерное расширение и существующие авторизованные вкладки пользователя: история,
исходные документы, сверка расходов и подача через форму ЛК.

## Подключение

Подключите этот каталог в каталог навыков своего агента. Например, для Claude Code:

```bash
git clone git@github.com:Dekkee/chaika.git ~/git/chaika
ln -s ~/git/chaika ~/.claude/skills/chaika
```

Браузерный инструмент должен поддерживать расширение с доступом к существующим
вкладкам. Агент проверяет доступные возможности, авторизацию, профиль и владельца
медкарты; для Downloads и upload локальных файлов — фактические разрешения расширения.
Недоступные шаги выполняет пользователь штатным способом. hCaptcha на Taxcom
пользователь проходит сам, после чего сохраняется оригинальный PDF чека.

## Использование

```text
/chaika visits
/chaika docs 25.06.2026
/chaika details <визит>
/chaika refund
```

Перед подачей сверяются оплаты и документы Чайки, активные и архивные заявления Альфы,
локальные PDF, маркеры и CSV. Отдельные услуги одного чека можно предъявлять отдельными
заявлениями согласно программе: каждое содержит свою сумму и описание части, общий
чек/акт и соответствующий протокол. Повторное предъявление того же расхода исключается.

До передачи медицинских/персональных документов агент показывает состав данных и
получателя и получает согласие на upload. Финальная отправка каждого заявления требует
отдельного подтверждения. Регистрация немедленно фиксируется локально; задержка
появления в списке не служит причиной повторной отправки.

Условия полиса, лимиты, пациенты и особенности архива определяются приватным runbook
оператора. В shclauder это `knowledge/personal/chaika-family-archive.md`. Универсального
лимита skill не устанавливает.

## Учёт и безопасность

`SKILL.md` описывает браузерный сценарий, сверку, подтверждения и формат локального учёта.

Архив по умолчанию — `~/Downloads/chaika/`. Одна папка поддерживает несколько маркеров
`Заявление №<номер>.txt` и строк `Заявления.csv`, по одной на заявление. Первые 8 колонок
CSV сохраняются; дополнительные связывают пациента, чек и отдельную услугу. При
подтверждённой регистрации без номера сохраняется временный маркер и строка с пустым
номером; позже обновляется та же запись. Статусы сверяются и обновляются через
браузер. Подробнее см. `SKILL.md`.

Персональные данные, сессии и медицинские документы хранятся вне репозитория с
ограниченным доступом. `.gitignore` — дополнительная защита, не гарантия от случайного
коммита. Сведения о передаче данных страховщику показываются до upload.
